Agent Chrome MCP
Your real Chrome, for every coding agent

Pair this Chrome profile

  1. In a terminal, run agent-chrome-mcp pair (or npx agent-chrome-mcp pair). It prints a code like ABCDE-FGHJK.
  2. Click the Agent Chrome MCP icon in the toolbar (pin it from the puzzle-piece menu), paste the code and press Connect.
  3. Ask your agent to "open example.com in Chrome". Its tabs appear in their own tab group with a glowing border while it works.

Repeat in every Chrome profile you want agents to use. Each profile shows up as its own browser in list_browsers.
