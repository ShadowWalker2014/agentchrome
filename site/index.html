Your real Chrome,
for every coding agent.

A Chrome extension and remote MCP server. Claude Code, Codex, Gemini, Antigravity, Grok, Muse, Cursor and opencode drive your signed-in Chrome profiles, each in its own tab group, with a glowing border while they work.

$curl -fsSL __SERVER__/install | sh

One command: account, every agent configured, skill linked, extension unpacked, pairing code. Fully local: add -s -- --local

Everything the first-party extensions do

Every tool name Claude in Chrome uses, plus what it lacks: multiple Chrome profiles and video clips.

Full browser control

Click, type, keys, scroll, drag, zoom, navigate, accessibility refs, find, form fill, page text, JavaScript, uploads, dialogs.

A tab group per agent

Each session gets its own named, colored group. Rename, recolor, collapse, move or ungroup with tab_groups.

Screenshots and video

Viewport, full-page and zoomed shots. MP4 clips or GIFs with click highlights, returned as download links.

Many Chrome profiles

Pair Work, Personal and client profiles. Pick one with list_browsers and select_browser, or per call.

Secure by default

Hashed keys and per-profile device tokens, single-use pairing codes, OAuth 2.1 with PKCE, revocation, a Stop button on every page.

Cloud or local

Cloudflare Workers and Durable Objects, one command to deploy your own, or fully local on 127.0.0.1.

Works with your agents

Setup writes the MCP entry for each one and symlinks a shared skill.

Or add it by hand

API key in a header, or OAuth with no secrets in config files.

# API key
claude mcp add --scope user --transport http agent-chrome __SERVER__/mcp \
  --header "Authorization: Bearer $(agent-chrome-mcp key)"

# OAuth: the sign-in page asks for your account key once
claude mcp add --scope user --transport http agent-chrome __SERVER__/mcp
