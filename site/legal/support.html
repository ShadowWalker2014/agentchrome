Support

We usually reply within two business days.

  • Email: support@agentchrome.dev
  • Bugs and feature requests: GitHub issues
  • Security reports: a private security advisory
  • Documentation: README and the install guide

Common problems

ProblemFix
The app says no browser is connectedOpen Chrome and click the Agent Chrome icon. It should say Connected. If not, press Sign in to connect.
A tool says the session is pausedYou pressed Stop on the page, or Cancel on Chrome's "started debugging this browser" bar. Press Resume in the extension popup.
Claude or ChatGPT can't connectRemove the connector and add https://agentchrome.dev/mcp again, then sign in.
Local file:// pages don't openIn chrome://extensions, open Agent Chrome > Details and turn on Allow access to file URLs.
